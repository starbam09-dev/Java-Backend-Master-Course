# ROADMAP.md

This roadmap describes the long-term development path for Java-Backend-Master-Course.

`MASTER_BOOK.md` remains the authority for lesson order and curriculum rules.

## Phase 0: Repository Foundation

Goal: Create the stable structure for a long-term textbook repository.

Status: Complete

Scope:

- Create required root documents
- Create required folders
- Create lesson placeholders from `Lesson01` to `Lesson50`
- Define Codex working rules
- Define status tracking
- Create first commit and push to GitHub

## Stage 1: Authoring Environment

Goal: Prepare a repeatable authoring environment for writing all 50 lessons.

Status: Complete

Scope:

- Create reusable Markdown templates under `templates/`
- Create reusable authoring prompts under `prompts/`
- Create phase-oriented workspaces under `workspace/`
- Create diagram source groups under `resources/diagrams/`
- Create project workspaces under `projects/`
- Create `KnowledgeMap.md` with the Java to ERP learning flow
- Update repository documentation for the new authoring structure

## Phase 1: Java Recovery, Lesson01 to Lesson10

Goal: Rebuild Java fundamentals with business-domain examples.

Expected focus:

- Java project setup
- Variables and types
- Operators
- Control flow
- Methods
- Arrays
- Basic class usage
- IntelliJ workflow
- Git basics connected to daily practice

## Phase 2: OOP, Lesson11 to Lesson20

Goal: Build object-oriented thinking for backend service design.

Expected focus:

- Class and object modeling
- Encapsulation
- Constructor design
- Inheritance
- Polymorphism
- Interface
- Abstract class
- Package structure
- Domain modeling

## Phase 3: Collection, Lesson21 to Lesson30

Goal: Use Java collections as preparation for service-layer and data-processing logic.

Expected focus:

- `List`
- `Set`
- `Map`
- Generics
- Iteration
- Sorting
- Filtering
- Simple inventory and order data handling

## Phase 4: Spring Boot, Lesson31 to Lesson40

Goal: Connect Java knowledge to web backend development.

Expected focus:

- Spring Boot project structure
- Controller
- Service
- Repository
- DTO
- REST API
- Validation
- Exception handling
- Swagger
- MyBatis connection

## Phase 5: ERP, Lesson41 to Lesson50

Goal: Build an ERP-oriented backend project.

Expected focus:

- ERP domain analysis
- Employee management
- Product management
- Inventory management
- Supplier management
- Order management
- Authentication and JWT
- Oracle schema design
- Docker deployment
- Linux operation basics

## Publication Track

Goal: Prepare the repository for GitBook and PDF output.

Expected focus:

- Markdown consistency
- Diagram conventions
- Image asset management
- PDF build workflow
- Review checklist
- Versioned releases
