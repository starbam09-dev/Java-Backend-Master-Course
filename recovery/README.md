# Recovery

The `recovery/` folder stores the user's learning recovery records.

## Purpose

- This folder is used to record the user's learning recovery history.
- One Recovery document should be written for each Lesson.
- Codex may read Recovery documents.
- Codex must not modify or create Recovery documents unless the user explicitly requests it.
- Recovery documents are the user's private learning records and must be used only as reference material for designing the next Lesson more appropriately.

## Ownership

Files under `recovery/` are user-owned learning journals.

Codex must treat this folder as read-only unless the user explicitly asks Codex to create or edit a Recovery document.
