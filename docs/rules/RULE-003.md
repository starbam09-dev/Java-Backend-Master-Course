# RULE-003: Documentation Source and Publication

## Rule

Markdown is the source of truth for JBMC documentation and textbook content.

## Requirements

- Write primary content in Markdown.
- Generate PDF outputs from Markdown sources.
- Keep generated publication files separate from source documents.
- Keep documentation compatible with GitBook and PDF workflows where practical.

## Rationale

Source-first documentation keeps the project maintainable in Git while still supporting future publication.
