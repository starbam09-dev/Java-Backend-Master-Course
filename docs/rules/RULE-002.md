# RULE-002: Lesson Structure Preservation

## Rule

Every lesson must follow the exact section order defined in `MASTER_BOOK.md`.

## Requirements

- Do not reorder lesson sections.
- Do not remove required sections.
- Do not rename required sections without an explicit curriculum decision.
- Do not write lesson content before the user requests it.

## Rationale

A fixed structure makes lessons easier to write, review, publish, and maintain.
