# RULE-001: MASTER_BOOK Authority

## Rule

`MASTER_BOOK.md` is the highest-priority curriculum document in JBMC.

## Requirements

- Check `MASTER_BOOK.md` before creating or editing lessons.
- Do not change lesson order unless `MASTER_BOOK.md` is explicitly revised.
- Do not create competing curriculum structures in other documents.

## Rationale

JBMC is a long-term textbook project. A single curriculum authority prevents drift and keeps all future work aligned.
