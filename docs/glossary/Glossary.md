# Glossary

This glossary defines shared terminology for Java-Backend-Master-Course.

`MASTER_BOOK.md` remains the authority for curriculum order.

## Terms

### ADR

Architecture Decision Record. A document that records a stable project-level decision and its consequences.

### ERP

Enterprise Resource Planning. In JBMC, ERP means business software that manages domains such as employees, products, inventory, suppliers, orders, and related workflows.

### Lesson

A structured learning unit under `lesson/LessonXX/`. Every lesson must follow the required section order defined in `MASTER_BOOK.md`.

### Markdown Source

The original editable document format for the textbook. PDF and GitBook outputs are generated from Markdown.

### Source of Truth

The document or file that has final authority for a specific topic. For curriculum order and lesson structure, `MASTER_BOOK.md` is the source of truth.

### Spring Boot Connection

The part of a lesson that explains how a concept appears later in Spring Boot development.

### ERP Connection

The part of a lesson that explains how a concept helps build ERP systems.

### Placeholder

An empty folder or minimal file used to reserve structure before actual content is written.
