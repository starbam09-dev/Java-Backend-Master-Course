# ADR-006: ERP Integration

## Status

Accepted

## Context

The final direction of JBMC is not only language study. The repository must guide the learner toward building practical ERP backend systems.

## Decision

ERP integration is a permanent design goal of JBMC.

Lessons, examples, diagrams, and projects should gradually prepare the learner for ERP domains such as employee management, product management, inventory, suppliers, orders, authentication, and reporting.

## Principles

- ERP concepts should appear progressively.
- Early lessons may use simple ERP-related objects.
- Later lessons should connect Java, Spring Boot, Oracle, MyBatis, JWT, Docker, and Linux into a backend system.
- ERP examples must remain understandable at the learner's current stage.

## Consequences

- ERP language and examples should be consistent across the repository.
- Domain terminology should be tracked in `docs/glossary/Glossary.md`.
- The final ERP project should feel like the natural result of the earlier lessons.
