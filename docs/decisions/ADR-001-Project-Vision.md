# ADR-001: Project Vision

## Status

Accepted

## Context

Java-Backend-Master-Course is a long-term repository intended to become a publication-ready backend development textbook and knowledge base.

The repository must not drift into a loose collection of disconnected notes, examples, or temporary practice files.

## Decision

JBMC exists to train a learner into a backend developer who can build ERP systems.

The repository will treat Java, Spring Boot, MyBatis, Oracle, Git, REST API, JWT, Docker, and Linux as connected parts of one backend development path.

## Principles

- The repository is a textbook and knowledge base, not a short lecture archive.
- `MASTER_BOOK.md` is the curriculum authority.
- Lesson order is fixed by `MASTER_BOOK.md`.
- Long-term consistency is more important than short-term convenience.
- Business-domain thinking is required throughout the course.

## Consequences

- New documents must support the long-term textbook goal.
- Examples, diagrams, and projects must eventually connect to ERP capability.
- Temporary material must not become a competing source of truth.
